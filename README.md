# IK2202-Quantitative-Analysis-Step-Counter

This repository contains the quantitative data analysis workflow completed for the KTH II2202 course exercise, analyzing the Kaggle dataset *iPhone Step Counter Apps, Prices, and Widgets*. Using Python (`analysis.py`), the project preprocesses app records and survey data (`step-counter-survey.csv`/`.json`) to conduct exploratory data analysis and statistical evaluations, examining how independent variables such as widget support, price tiers, and age ratings influence dependent metrics like user ratings and popularity. The resulting visualizations (`fig1_distribution.png` through `fig4_power.png`) illustrate variable distributions, correlation patterns, and statistical power to support the quantitative conclusions and sample-size evaluations required for the assignment report.
